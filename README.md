# 🚀 Personal Portfolio Website — Tashila Dilshan

A modern, responsive personal portfolio website built with a **Futuristic Dark & Neon Glassmorphism** theme. It showcases my work as a Full-Stack Software Engineer and Lecturer, featuring real-world client projects, desktop/web applications, and a functional contact form.

🌐 **Live Demo:** [View Live Website](YOUR_VERCEL_LIVE_LINK)

---

## ✨ Key Features

- **Futuristic UI/UX:** Dark theme with Neon cyan accents, Glassmorphism cards, and smooth scroll animations (AOS).
- **Floating Pill Navbar:** Sticky glassmorphic navigation bar with smooth section scrolling and mobile offcanvas drawer.
- **Featured Projects Showcase:** Responsive grid highlighting real-world client projects, enterprise desktop apps, and 3D web experiences with tech stack badges.
- **Functional Contact Form:** Integrated with **Web3Forms** and JavaScript Fetch API for instant email delivery, custom success/error alerts, and automatic form reset without page redirection.
- **Fully Responsive:** Optimized for Desktop, Tablet, and Mobile screens using Bootstrap 5.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Glassmorphism), Bootstrap 5, Vanilla JavaScript (ES6+)
- **Animations & Icons:** AOS (Animate On Scroll), Font Awesome
- **Contact Form Backend:** Web3Forms API
- **Hosting / Deployment:** Vercel
